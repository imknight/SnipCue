# Changelog

## 0.1.0 — unreleased

First public version.

- Products, questions and answers with optional labels, stored locally in IndexedDB.
- Side panel: product switcher, one box to search or save a question, click-to-copy cards, keyboard navigation, most-used answers first.
- Save selected text as a question from the right-click menu.
- Copy AI prompt with open questions first; paste the AI's reply, review and save, with copyable error messages for the AI.
- Optional per-product JSON feeds (raw GitHub or Gist) mirrored into the library.
- Library page with read-first questions, autosaving edits, filters, undo for deletes, backup and restore.
- System, light and dark themes.
